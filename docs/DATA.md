## 試算表欄位（「IPE問卷回應」工作表）

欄位順序**由 `gas/Code.gs` 的 `COLUMNS` 決定**。請不要手動在試算表插入或刪除欄位，否則資料會錯位。

| 欄 | 標題 | key |
| --- | --- | --- |
| A | 填答時間 | timestamp |
| B | 課程日期 | courseDate |
| C | 測驗階段 | phase（前測／後測） |
| D | 姓名 | name |
| E | 人事號 | empId（純文字格式，保留開頭 0） |
| F | 單位科別 | unit |
| G | 職類 | job |
| H | 職級 | rank |
| I–N | IPE1–IPE6 | ipe1–ipe6 |
| O | IPE 平均 | ipeAvg（GAS 自動計算） |
| P | 最具收穫的環節（複選） | gain |
| Q | 團隊表現最出色的面向 | teamBest |
| R | IPE 活動整體滿意度 | overall |
| S | 可加強或改進的面向 | comment |

前測的 P–S 欄為空白。

## 前後測配對規則

儀表板會把同一個人的前測與後測配成一對，用來算「配對差異」與配對 t 檢定。

**辨識同一個人：**

- **有人事號** → 只看人事號（姓名寫法不同也能配上）
- **沒有人事號** → 看「姓名＋單位科別」（忽略空白與英文大小寫，`10A` = `10a`）

**配對條件：** 每筆後測，找同一人、課程日期在 **14 天內**、填答時間早於該後測、且最接近的那筆前測。

**常見配不上的原因：**

- 無人事號者前後測的單位科別寫法不同（例：`GI` vs `腸胃科`）
- 前測有填人事號、後測沒填（或相反）
- 前後測相隔超過 14 天

**隱私：** 儀表板拿不到姓名與人事號，只拿到 GAS 用 SHA-256 雜湊後的「配對代碼」。

## 修改題目時要同步改的地方

| 想改的東西 | `index.html` | `dashboard.html` | `gas/Code.gs` |
| --- | --- | --- | --- |
| 職類選項 | `<select name="job">` | — | — |
| 職級選項 | `<select name="rank">` | `RANKS`（只影響篩選選單排序） | `RANKS`（送出時檢核） |
| IPE 題目文字（不改題數） | `IPE` 陣列的 `t`／`pre`／`post` | — | — |
| IPE 面向名稱 | `IPE` 的 `dim` | `DIMS` | `COLUMNS` 的標題（只影響新建的試算表） |
| 收穫環節／團隊面向選項 | `GAIN`、`TEAM` | `GAIN`、`TEAM` | — |
| 新增一個欄位 | 表單 HTML＋送出的 `data` | 需要的話加進 CSV 的 `cols`／`head` | `COLUMNS` 加一列 |

**新增欄位的注意事項：** 已經有資料的試算表不會自動多出新欄位。
建議把新欄位加在 `COLUMNS` 的**最後面**，再手動在試算表最右邊補上標題；
若一定要插在中間，要像 `migrateRank_()` 那樣寫一段自動插欄的程式，否則新舊資料會錯位。

改完 GAS 記得「管理部署作業 → 編輯 → 新版本」，並**先更新 GAS、再更新網頁**。
