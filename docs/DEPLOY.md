# 部署與更新

系統分兩半，**改哪一半就部署哪一半**：

| 部分 | 檔案 | 放在哪 | 怎麼更新 |
| --- | --- | --- | --- |
| 前端（網頁） | `index.html`、`dashboard.html`、`config.js` | GitHub repo → GitHub Pages | commit 到 `main`，約 1–10 分鐘後生效 |
| 後端（資料） | `gas/Code.gs` | Google 試算表的 Apps Script | 貼上程式碼 → 部署「新版本」 |

---

## 一、第一次部署

### 1. 建立試算表與 GAS

1. 建立一份新的 Google 試算表（建議用院方／單位的公用帳號，不要用個人帳號，以免人員異動後資料拿不到）
2. 試算表上方選單 → **擴充功能 → Apps Script**
3. 把 `gas/Code.gs` 的內容**整份**貼上，取代預設的 `function myFunction() {}`
4. 檔案最上面的 `SPREADSHEET_ID`：
   - 新院區**改成 `''`（空字串）** 即可，程式會自動使用這份試算表
   - 或填入試算表網址中 `/d/` 與 `/edit` 之間的那串 ID
5. 按 💾 儲存

### 2. 執行 setup()（建立標題列＋授權）

1. 上方函式下拉選單選 `setup` → 按 **執行**
2. 跳出授權視窗 → 選帳號 →「進階」→「前往（不安全）」→ 允許
   （這是 Google 對自建程式的標準警告，程式只會存取這份試算表）
3. 回到試算表，應該會多一個「IPE問卷回應」工作表，第一列是橘色標題

### 3. 部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**
2. 齒輪 ⚙ → 類型選 **網頁應用程式**
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學員不需要登入 Google 就能填答）
4. 按 **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）

> 測試：把 `/exec` 網址貼到瀏覽器，看到 `{"ok":true,"msg":"IPE 問卷 API 運作中"}` 就成功了。

### 4. 設定前端

1. 打開 repo 根目錄的 `config.js`
2. 把 `gasUrl` 換成剛剛的 `/exec` 網址；`hospital`、`dept` 改成院名與單位
3. commit 到 `main`

### 5. 開啟 GitHub Pages

1. GitHub repo → **Settings → Pages**
2. Source：**Deploy from a branch**；Branch：**main**、資料夾 **/ (root)** → Save
3. 等 1–2 分鐘，頁面上方會顯示網址：
   - 問卷：`https://<帳號>.github.io/<repo>/`
   - 儀表板：`https://<帳號>.github.io/<repo>/dashboard.html`
4. 用問卷網址做 QR code 給學員掃

### 6. 驗收

- [ ] 用手機填一筆「前測」、一筆「後測」（同一個人事號）
- [ ] 試算表出現兩列資料
- [ ] 儀表板能看到資料，且「配對 n」= 1
- [ ] 測完把試算表中的測試資料列刪掉

## 二、日後更新

### 只改了網頁（`index.html`／`dashboard.html`／`config.js`）

commit 到 `main` 就好。GitHub Pages 有快取，手機上沒看到變化時可重新整理或等幾分鐘。

### 改了 `gas/Code.gs`

1. 把新的 `gas/Code.gs` 整份貼到 Apps Script，**保留**你那份的 `SPREADSHEET_ID` 設定，儲存
2. 如果這次有新增欄位，手動執行一次 `setup()`
3. **部署 → 管理部署作業** → 選現有的那個部署 → ✏️ 編輯 → 版本選 **新版本** → 部署

> ⚠️ 一定要用「管理部署作業 → 編輯 → 新版本」。
> 如果按成「新增部署作業」，會產生**新的網址**，舊網址還是跑舊程式，前端就要跟著改 `config.js`。

### 前後端都改了

**先更新 GAS，再更新網頁。** 新網頁送出的資料如果舊 GAS 不認得，學員會送出失敗。

## 三、常見問題

| 狀況 | 原因／處理 |
| --- | --- |
| 問卷送出顯示「送出失敗」 | `config.js` 的 `gasUrl` 錯誤，或 GAS 部署時存取權不是「所有人」 |
| 儀表板顯示「資料讀取失敗」 | 同上；或 GAS 改了程式但沒有部署新版本 |
| 改了 GAS 但行為沒變 | 只按了儲存，沒有「管理部署作業 → 編輯 → 新版本」 |
| 人事號開頭的 0 不見了 | 試算表 E 欄要是「純文字」格式，`setup()` 會自動設定；若手動動過欄位，請重新設定 |
| 出現「工作表欄位與程式不符」 | 有人手動插入／刪除了試算表欄位，請對照 [DATA.md](DATA.md) 的欄位順序修正標題列 |
